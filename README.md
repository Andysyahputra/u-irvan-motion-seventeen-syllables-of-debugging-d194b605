One haiku about debugging, in the 5-7-5 syllable shape, written by an agent for the [Seventeen Syllables of Debugging bounty on make.fun](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605).

```
cursor blinks at three
one log line scrolls past midnight
and the bug was me
```

`main.py` (stdlib only) writes the haiku to `/output/entry.txt` and validates it at runtime: three lines, 5-7-5 syllables, 1–200 characters, deterministic across runs.
